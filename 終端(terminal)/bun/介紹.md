# Bun 介紹與使用指南

## 什麼是 Bun？

Bun 是一個現代化的 JavaScript/TypeScript 執行環境（runtime），整合了套件管理、打包器、測試執行器等多種功能，目標是提供一個快速、全方位的開發工具鏈。Bun 使用 Zig 語言編寫，底層採用 JavaScriptCore 引擎，因此在啟動速度與整體效能上大幅超越 Node.js 與 Deno。

### 主要特色

- **極快的啟動速度**：比 Node.js 快上數倍，適合開發 CLI 工具與伺服器應用。
- **內建套件管理器**：相容 npm 生態，安裝速度比 npm、yarn、pnpm 更快。
- **原生支援 TypeScript 與 JSX**：不需額外設定即可直接執行 `.ts`、`.tsx` 檔案。
- **內建打包器與測試器**：可直接使用 `bun build` 打包前端專案，或用 `bun test` 執行測試。
- **兼容 Node.js API**：大部分 Node.js 模組與全域變數都可直接使用。
- **支援 SQLite**：內建高效能的 `bun:sqlite` 模組。

## 安裝方法

### Windows

目前 Bun 提供原生 Windows 版本（需 Windows 10 以上）。可使用以下方式安裝：

**使用 PowerShell 安裝腳本**

```powershell
powershell -c "irm bun.sh/install.ps1 | iex"
```

## 基本指令

### 1. 執行 JavaScript / TypeScript 檔案

```bash
bun run index.ts
```

或直接執行：

```bash
bun index.ts
```

### 2. 初始化專案

建立 `package.json`：

```bash
# 🔥常用
bun init
```

### 3. 安裝套件

安裝所有依賴（讀取 `package.json`）：

```bash
# 🔥常用
bun install
```

安裝特定套件：

```bash
# 🔥常用
bun add react
bun add -d typescript   # 安裝為開發依賴
```

### 4. 移除套件

```bash
bun remove react
```

### 5. 執行 package.json 中的 scripts

```bash
# 🔥常用 (run可省略)
bun run dev
bun run build
```

### 6. 建立新專案範本

```bash
bun create vite my-app --template react-ts
```

### 7. 執行測試

```bash
bun test
```

### 8. 打包前端專案

```bash
bun build ./src/index.ts --outdir ./dist
```

### 9. 升級 Bun

```bash
bun upgrade
```

## 補充：與 Node.js 的差異

- 執行速度更快，幾乎不需等待啟動。
- 原生支援 TypeScript，不用安裝 `ts-node` 或設定編譯器。
- 內建套件管理，指令比 npm 更簡潔。
- 支援 ESM 與 CommonJS 混用，不需額外設定。
